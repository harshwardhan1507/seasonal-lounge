# Security Policy

## Supported versions

Until version 1.0, security fixes are applied to the latest published minor release.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting feature on this repository, or contact the maintainer privately through the contact information on the GitHub profile.

Include the affected version, reproduction steps, potential impact, and any suggested mitigation. You can expect an acknowledgement within seven days.
